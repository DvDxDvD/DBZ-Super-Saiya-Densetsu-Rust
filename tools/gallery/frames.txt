# Each line makes two pictures from the reference replay of that name (you make the replays from your
# own ROM: `cargo run --release -p xtask -- make-replays`, and the `secret-*` ones with
# `tools/saves/secrets.sh`), played for that many frames:
#   cmp-<name>-classic.png      the original picture, as the Classic mode draws it

# tools/gallery/) is applied to the Remastered picture only: it presses the new menus' keys from that
# frame (the replay stops there) to show a screen that the original does not have. In the Remastered
# mode the new menus also draw by themselves over a replay frame where the original has its menu open.
